# Fintech Customer Experience Analytics Pipeline

## Project Overview
This repository contains an end-to-end data engineering and text analytics pipeline designed for Omega Consultancy. It extracts, processes, cleans, and stores customer feedback for major Ethiopian mobile banking apps (**Commercial Bank of Ethiopia, Bank of Abyssinia, and Dashen Bank**) to address user retention risks, optimize tech support, and prioritize future features.

## Task 1: Data Collection & Preprocessing Architecture

### Scraping Methodology
- **Tooling Engine:** Built using `google-play-scraper` in Python.
- **Parameters applied:** Targeted English language reviews (`lang='en'`) matching the target market footprints. 
- **Target Thresholds:** Enforced a minimum constraint of 400+ clean reviews per target banking institution.

### Data Cleaning Rules applied:
1. **Null Elimination:** Dropped any rows completely missing review messages or numerical star ratings.
2. **Deduplication:** Filtered out identical concurrent reviews generated by network retries.
3. **Date Uniformity:** Standardized variable system timestamps into clean `YYYY-MM-DD` strings.
